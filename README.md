# CRM_YE

מערכת CRM למלווה פרטי שמסייע ללקוחות להגיש בקשות למשרדי ממשלה (סיוע בשכר דירה
דרך מילגם / אלונים / מעוף ועוד) — מרגע איסוף המסמכים, דרך ההגשה והמעקב, ועד
ההחלטה, סגירת התיק והתשלום.

**Next.js 15 · React 19 · PostgreSQL · Resend (אימייל) · Meta WhatsApp Cloud API**

## מה יש בפנים

- **לקוחות ותיקים** — פס שלבים מלא, רשימת מסמכים נדרשים לכל תיק, סימון תיק תקוע,
  החלטות וחקירות, שיוך לעובדים
- **תיקיית מסמכים לכל לקוח** + **עורך PDF/תמונות** בדפדפן (טקסט בעברית, עט, מדגש)
- **שליחת מסמכים ללקוח** בקישור מאובטח אחד (אימייל / וואטסאפ), בתוקף 14 יום
- **תשלומים וחובות** — שכר טרחה, תקבולים, סטטוס תשלום ידני
- **משימות ותזכורות** — נשלחות אוטומטית באימייל ו/או וואטסאפ בזמן שנקבע, פעם אחת בדיוק
- **צ׳אט צוות** — ערוץ כללי והודעות פרטיות, קבצים, הקלטות קוליות, תזכורות
- **מנהלים ועובדים** — עובד רואה רק את התיקים שפתח או ששויכו אליו
- **הגדרות** — שם העסק, חברות, תבניות מסמכים, אמצעי תשלום ושמות שלבים — בלי לגעת בקוד

## אבטחה

- סיסמאות מוצפנות (bcrypt), התחברות נשמרת בשרת: יציאה, השבתת עובד או החלפת סיסמה
  **מנתקות מיד**
- נעילה זמנית אחרי ניסיונות סיסמה שגויים (לפי חשבון ולפי כתובת IP)
- הגנה מפני בקשות זדוניות מאתרים אחרים (CSRF) וכותרות אבטחה (CSP, HSTS)
- קבצים שהועלו לעולם לא מורצים כדף אינטרנט — רק PDF ותמונות נפתחים בדפדפן, השאר יורד כקובץ
- איפוס סיסמה בקוד חד-פעמי (אימייל / וואטסאפ) עם הגבלת ניסיונות
- השרת **מסרב לעלות** עם הגדרה לא בטוחה (בלי סיסמה, סוד חלש, כתובת בלי HTTPS)

## התקנה

מדריך מלא — שרת חדש (Docker), CloudPanel/pm2, העברת נתונים וגיבויים:
**[DEPLOY.md](DEPLOY.md)**. חיבור וואטסאפ: **[docs/WHATSAPP-SETUP.md](docs/WHATSAPP-SETUP.md)**.

הפעלה מקומית לפיתוח:
```bash
npm install
cp .env.example .env.local      # למלא DATABASE_URL, ADMIN_PASSWORD, ADMIN_SESSION_SECRET
npm run db:migrate
npm run dev
```

## פקודות

| פקודה | מה עושה |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` / `npm start` | בנייה / הפעלה (מריץ קודם עדכוני מסד נתונים) |
| `npm run db:migrate` · `db:status` | עדכוני מבנה מסד הנתונים |
| `npm run db:import-json:dry-run` · `db:import-json` | ייבוא חד-פעמי מהגרסה הישנה (קבצי JSON), עם אימות מלא |
| `bash scripts/backup.sh [תיקייה]` | גיבוי מלא — מסד נתונים + קבצים |
| `bash scripts/restore.sh <גיבוי>` | שחזור (גם לשרת חדש) |

## מבנה

```
app/            דפים ו-API (Next.js App Router)
components/     רכיבי ממשק
lib/            store.ts (גישה לנתונים), chat.ts, db.ts, notify.ts (Resend/WhatsApp),
                reminders.ts (תזמון תזכורות), sessions.ts, rate-limit.ts, domain.ts
migrations/     מבנה מסד הנתונים (SQL)
scripts/        migrate · import-json · backup · restore
data/           (לא ב-git) מסמכי הלקוחות, קבצי צ׳אט, תבניות
```
